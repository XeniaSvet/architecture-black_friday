# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

## Как проверить

Откройте в браузере http://localhost:8080


### Тестирование скорости кэширования (эндпоинт /helloDoc/users)

* **Критерий успешности**: Время для второго и последующих запросов из кэша должно составить меньше 100мс.
