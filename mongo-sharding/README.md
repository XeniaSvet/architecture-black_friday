# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

## Шаги, выполняемые при инициализации кластера

Контейнер `mongo_init` последовательно выполняет внутри сети следующие действия (описаны в `./scripts/mongo-config.sh`):

1. **Ожидание готовности (Healthcheck)** всех реплик и роутера.
2. **Инициализация Config Server** как набора реплик.
3. **Инициализация Shard 1 и Shard 2**.
4. **Регистрация шардов на роутере `mongos_router`**.
5. **Включение шардирования** для базы данных `somedb` и коллекции `helloDoc`.
6. **Сидинг данных**: генерация и пакетная вставка 1500 документов.
